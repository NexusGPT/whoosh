# Graph fixtures

Hand-authored in the shapes Microsoft documents for Graph v1.0 (delta query for messages, mailFolders,
subscriptions, change and lifecycle notifications, the 429 body). They are NOT captures from a tenant:
no mail account is connected and nothing is sent. Tenants and addresses are invented and live on
example.net. `{BASE}` in a link is replaced by the local stub's 127.0.0.1 address when it serves the file.
Shapes not yet checked against a real tenant: the 410 body code, lifecycle `missed` payloads.
